# Bubu Jump

Juego de saltos estilo Doodle Jump, hecho en Rust con macroquad.

## Controles
- **PC:** flechas o A/D para moverte, espacio para disparar, Esc para pausa.
- **Celular:** toca la izquierda o derecha para moverte y el centro para disparar.

## Descargar
Ve a la pestaña **Actions**, abre la última compilación y descarga el APK en **Artifacts**.
